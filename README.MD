# Запуск

## Требования

Поддерживаются Linux, Windows и MacOS. В системе должны быть установлены:
- Python, версия минимум 3.12
- Make

## Запуск

Сделать копию config-example.yml:

```shell
cp config-example.yml config.yml
```


## Вариант 1. Через Makefile
Запустить Makefile внутри папки с проектом:

```shell
make run
```


## Вариант 2. Вручную

В папке с игрой создать и активировать venv:
```shell
python3 -m venv ./

source ./bin/activate

pip install -r requirements.txt
```

Запустить через main.py:
```shell
python3 main.py
```

# Настройки

Настройки указываются в файле config.yml:

| Опция              | Описание                                                                    | Допустимые значения                                                                       | Пример     |
|--------------------|-----------------------------------------------------------------------------|-------------------------------------------------------------------------------------------|------------|
| resolution         | Разрешение экрана                                                           | ширина x высота                                                                           | `1280x720` |
| fps                | Частота кадров                                                              | `30`, `60`, `120`                                                                         | `60`       | 
| fullscreen         | Полноэкранный режим                                                         | `true`, `false`, `yes`, `no`, `0`, `1` (стандартные значения в YAML для булевых значений) | `true`     |
| display            | Индекс дисплея, на который должно выводиться изображения                    | От `0` и выше                                                                             | `0`        |
| vsync              | Вертикальная синхронизация                                                  | `true`, `false`, `yes`, `no`, `0`, `1` (стандартные значения в YAML для булевых значений) | `true`     |
| hardware_rendering | Аппаратный рендеринг                                                        | `true`, `false`, `yes`, `no`, `0`, `1` (стандартные значения в YAML для булевых значений) | `true`     |
| music              | Громкость музыки                                                            | `0.0` - `1.0`                                                                             | `0.5`      |
| sound              | Громкость звуков. **При значении >0 и отсутствии звуковых файлов крашится** | `0.0` - `1.0`                                                                             | `0.5`      |
| language           | Язык игры                                                                   | `russian`, `english`                                                                      | `russian`  |

## Управление

Поддерживается управление с клавиатуры. Названия клавиш взяты из pygame и используются для получения
кодов через [pygame.key.key_code](https://www.pygame.org/docs/ref/key.html#pygame.key.key_code).

Действия в игре:

| Действие | Описание        |
|----------|-----------------|
| up       | Вверх           |
| down     | Вниз            |
| left     | Влево           |
| right    | Вправо          |
| confirm  | Подтвердить     |
| back     | Отмена/назад    |
| pause    | Пауза           |
| jump     | Прыжок          |
| poop     | Отложить "мину" |




# Использование multitool.py для генерации новых объектов и обработчиков

## Объект

```shell
python multitool.py make:object <NAME> [OPTIONS]
```

**Аргументы**
- `<NAME>`: Название нового класса.

Название файла будет сгенерировано в snake_case из названия нового класса. Новый класс будет добавлен в `__init__.py`.

**Опции**
- `--parent <PARENTS>`: Родительский класс (или классы через запятую). По умолчанию `Object`.
- `--handler <HANDLER>`: Название класса обработчика. По умолчанию не подставляется (`None`).
- `--make-handler <PARENT_HANDLERS>`: Создать класс обработчика `КлассОбъекта + Handler`. Через запятую можно перечислить дополнительные родительские классы помимо `ObjectHandler`.

## Обработчик

```shell
python multitool.py make:handler <TARGET> [OPTIONS]
```

**Аргументы**
- `<TARGET>`: Класс объекта, которым управляет обработчик.

Название файла будет сгенерировано в snake_case из названия нового класса. Новый класс будет добавлен в `__init__.py`.

**Опции**
- `--parent <PARENTS>`: Родительский класс (или классы через запятую). По умолчанию `ObjectHandler`.
