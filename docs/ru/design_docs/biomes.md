## База людей
Оформление:

| Слой         | Содержимое          | Примечания                       |
|--------------|---------------------|----------------------------------|
| BACKGROUND_3 | Металлические стены | Схематичено, чтобы не мельтешить |
| BACKGROUND_2 | Техника мелкая      | Редко, чтобы не мельтешить       |
| BACKGROUND_1 | Сплошной пол        |                                  |
| FOREGROUND_1 |                     |                                  |
| FOREGROUND_2 | Техника крупно      | Редко, чтобы не мельтешить       |

Люди:
- Учёные
- Солдаты
- Вертолёты
- Самолёты-штурмовики
- Танки

Препятствия:
- Небоскрёбы, которые можно сбить, врезавшись в них несколько раз 
- Тесла-установки (соединяются между собой в цепь)
- Ракетные шахты. Не мешают, но если их активировать, то выпускают ракеты "земля-воздух"
- Мины. Взрываются с задержкой, когда динозавры входят в зону активации
