# Торнадо
Движутся навстречу игроку. Затягивают в себя динозавров на своём уровне.

# Ядовитые гейзеры
Наносит урон тяжёлым персонажам, мгновенно убивает мелких персонажей.

# Падающие сталактиты
Есть два типа: капающий и "мёртвый". Генерируются случайно.

"Мёртвый" сталактит срывается и падает, когда Т-Рекс оказывается в его "зоне видимости".

Капающий сталактит роняет капли через случайно определяемый интервал.

# Небоскрёбы
Мешают только [Т-Рексу](dinosaurs.md#тираннозавр) и [вертолётам](humans.md#вертолёт).
Нужно удариться в них несколько раз, чтобы опрокинуть.

Могут быть двух размеров: средний и высокий.

Средний падает с одного удара.

Высокий падает с двух.

При ударе [Т-Рекс](dinosaurs.md#тираннозавр) отскакивает от них назад.

При падении взрываются.

# Тесла-установки
Две башенки, создают между собой [молнию](objects.md#молния), которая уничтожает всё, что попадётся.

Интервал срабатывания и расстояние определяются при спауне.

Перед срабатыванием над катушками появляются маленькие молнии, сигнализирующие, что надо прыгать.

Можно взорвать "миной".

# Ракетные шахты
Не мешают ходьбе [Т-Рекса](dinosaurs.md#тираннозавр). Но если сбросить "мину" на пульт, выпускают одну [ракету](objects.md#ракета).

# Мины
При приближении [Т-Рекса](dinosaurs.md#тираннозавр) срабатывают и создают [поражающий взрыв](objects.md#поражающий-взрыв).
