# Велоцираптор

Класс: [Velociraptor](../../../objects/velociraptor.py)

Размер: 8x8

Спаунятся стайками по 3-4 особи. Пугливы: если в поле зрения появляется другой динозавр, начинают бежать в том же
направлении. Бегут в противополжную сторону от хищника. Не могут перепрыгнуть [кактусы](obstacles.md#кактус) и
[камни](obstacles.md#камень) - если добегают до них, то начинают прыгать на месте, пока не окажутся по другую сторону
от хищника, чтобы сбежать.

Боятся всех, кроме других велоцирапторов.
