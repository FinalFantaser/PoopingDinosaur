## Велоцираптор
Класс: [Velociraptor](../../../objects/velociraptor.py)

Размер: 8x8

Могут спауниться стайками по 3-4 особи. Пугливы: если в поле зрения появляется другой динозавр, убегают. Прячутся в колючках.

Боятся всех, кроме других велоцирапторов.

Если на велоцираптора сверху упадёт тираннозавр, его расплющит.

| Препятствие                                      | Взаимодействие                                      | Эффект от столкновения  |
|--------------------------------------------------|-----------------------------------------------------|-------------------------|
| [Кактус](obstacles.md#кактус)                    | Останаливается перед препятствием и скачет на месте | Динозавр погибает       |
| [Колючка](obstacles.md#колючка)                  |                                                     | Динозавр исчезает       |
| [Камень](obstacles.md#камень)                    | Останаливается перед препятствием и скачет на месте | Динозавр отлетает назад |
| [Дерево](obstacles.md#камень)                    | Останаливается перед препятствием и скачет на месте | Динозавр отлетает назад |
| [Папоротник](obstacles.md#папоротник)            |                                                     | Динозавр исчезает       |
| [Скелет динозавра](obstacles.md#скелетдинозавра) | Останаливается перед препятствием и скачет на месте | Динозавр отлетает назад |

## Птеродактиль
Класс: [Pterodactyl](../../../objects/pterodactyl.py)

Размер: 22х15

В состоянии покоя медленно летают вперёд и назад. Если в их поле видимости появляется любой динозавр, кроме птеродактиля,
летят в противоположную сторону от динозавра, набирая скорость.

## Трицератопс
Прёт, как бульдозер, через все препятствия. Пожирает растения.

Здоровье: 2HP

При получении урона отлетает в сторону. Когда погибает, создаёт на месте падения препятствие.

При столкновении с его рогами все динозавры превращаются в скелеты.

| Препятствие                                      | Взаимодействие | Эффект от столкновения              |
|--------------------------------------------------|----------------|-------------------------------------|
| [Кактус](obstacles.md#кактус)                    |                | Динозавр съедает препятствие        |
| [Колючка](obstacles.md#колючка)                  |                | Динозавр съедает препятствие        |
| [Камень](obstacles.md#камень)                    |                | Препятствие уничтожается со взрывом |
| [Дерево](obstacles.md#камень)                    |                | Препятствие уничтожается со взрывом |
| [Папоротник](obstacles.md#папоротник)            |                | Динозавр съедает препятствие        |
| [Скелет динозавра](obstacles.md#скелетдинозавра) |                | Препятствие уничтожается со взрывом |
